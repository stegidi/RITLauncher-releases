# RIT Launcher

Qui si trovano solo l'installer e gli aggiornamenti di RIT Launcher.

1. Apri l'ultima versione in [Releases](https://github.com/stegidi/RITLauncher-releases/releases/latest).
2. Scarica `RITLauncher-win-Setup.exe` e aprilo.

Serve avere già installato RIT. Gli aggiornamenti arrivano da soli quando apri l'app.
